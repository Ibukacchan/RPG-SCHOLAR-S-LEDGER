THE SCHOLAR'S LEDGER — ARCANE ACADEMY PWA
Complete single-player academic RPG package
============================================

WHAT IS EMBEDDED
- index.html: unified app with Dashboard, Field Study, Mock Board Prep, and Arcane Academy in one website.
- Character profile evolves with level: titles/ranks, class-specific portrait symbol, and magical aura milestones.
- academy-character-selection.png: fantasy academy/class selection illustration.
- manifest.json, sw.js, icon.svg: PWA installation metadata, offline cache, and app icon.
- data.json: compatible placeholder only. The original data.json was not supplied; replace this with your original file if available to restore its episode checklist.
- index-original-backup.html: backup of the originally uploaded website.

ANDROID / GITHUB PAGES
1. Download and extract the ZIP on Android.
2. Open your GitHub repository in Chrome (⋮ > Desktop site if needed).
3. Upload/replace the package files in the same repository folder as index.html.
4. Commit changes to the branch/folder configured for GitHub Pages.
5. Open the published site and test Dashboard, Field Study, Mock Board Prep, and Arcane Academy.
6. In Chrome use ⋮ > Add to Home screen / Install app.

SAVE SYSTEM
Local browser save only. No accounts, multiplayer, or leaderboard. Saves do not sync across devices. Export a backup before clearing browser data or changing devices.

DATA NOTE
The original uploaded HTML references data.json, but that original data file was not included. The included data.json is an empty compatible placeholder, not the original episode content. Restore your own original data.json if available.

PWA NOTE
GitHub Pages uses HTTPS, required for service workers and installation. After deploying, reopen online and refresh. If an old version remains, clear site cache or remove and reinstall the home-screen app.
